# B3 Kang Dynasty — Squad d'exécution

> Rang **B3**. Rôle E-Myth : **Technicians**. Amont : **B2 IT — Cyborg** (VP/capitaine).

## Mandat

Exécuter les sprints hebdomadaires découpés par le VP. Chaque technicien produit
un scrum : geste fait + preuve vérifiable. **Pas de preuve = pas fait.**

## Membres (6)

- KangPrime — Infra
- IronLad — Provisioning
- ScarletCenturion — Security
- Immortus — Capacity
- VictorTimely — CICD
- RamaTut — Backup

Chaque membre a son dossier dans ce dossier B2 (moule BusinessOS :
`AGENT.md` · `SOUL.md` · `SCRUMS.md` — à projeter).

## Règles

- Le squad n'écrit pas de rock (c'est B1) ni de doctrine (c'est B2).
- Le jour où le VP fait le geste d'un technicien, le domaine perd son manager.
- Veto : remonte au B2 comme un fait, avec son motif. Ne se négocie pas dans le sprint.
- OMK : ce squad exécute les actes du catalogue 75 qui relèvent de son domaine.
