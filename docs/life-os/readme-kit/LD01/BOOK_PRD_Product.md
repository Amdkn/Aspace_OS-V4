## Mission

Productiser sans dépendance aveugle. Discipline design anti-slop.

## Frameworks / processus clés

1. **Supply Chain Awareness** : pour chaque dépendance critique, 2 questions — sur quel
   moteur de calcul tourne mon outil ? le propriétaire est-il concurrent de mon
   écosystème ? (La valeur se consolide au niveau compute, pas modèle.)
2. **Skill vs MCP** : skill = rulebook chargé à la demande (le *jugement*) ; MCP = live
   connection permanente (les *composants*). Règle : par défaut skill, MCP seulement si justifié.
3. **Anti-AI Slop** : *commit to a real design direction before it writes anything* —
   forcer une direction au lieu des patterns safe par défaut.
4. **Functional UI vs Marketing UI** : deux skills séparés, jamais l'un pour l'autre
   (le fonctionnel reste *boring and plain*).
5. **Taste-preset** : 1 seul preset pické par projet, jamais stacké.
