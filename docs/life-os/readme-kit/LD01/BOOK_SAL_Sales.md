## Mission

Vendre par le diagnostic quantifié. **La première vente précède le produit**
(anti « build-then-pray »).

## Frameworks / processus clés

1. **SPIN** (Rackham) : Situation / Problem / **Implication** / Need-payoff — les questions
   Implication font ressentir le coût du problème.
2. **Gap Selling** (Keenan) : quantifier le gap état actuel ↔ état futur en € + timeline.
   Pas de gap quantifié = pas de deal.
3. **Challenger** (Dixon & Adamson) : teach / tailor / take-control — reframe l'acheteur.
4. **Never Split the Difference** (Voss) : tactical empathy, labeling, mirroring,
   calibrated questions ; viser *« That's right »* plutôt que « yes ».
5. **Million Dollar Weekend / the ASK** (Kagan) : pre-sell avant produit ; le « non »
   ne coûte rien. Segmentation 5 tiers par profondeur d'intention.
