# Fiche de collecte client — Onboarding (cas pilote : Avionté / Wise Staffing)

Actif franchise réutilisable : cette fiche est le guichet unique de collecte.
Le client la remplit **une fois** → Master Profile → projection sur les 19 tâches.
Cocher chaque item quand la donnée est reçue et vérifiée.

## A. Identité & contact → [Personal Info] + [W-4]
- [ ] Prénom, deuxième prénom, nom de famille (tels que sur la pièce d'identité)
- [ ] Email, téléphone
- [ ] Adresse complète : rue, complément, ville, état, ZIP, pays
- [ ] Adresse de paiement différente ? (oui/non — si oui, la fournir)
- [ ] Date de naissance (ISO AAAA-MM-JJ)
- [ ] Numéro de sécurité sociale (SSN) — canal sécurisé uniquement

## B. Parcours → [Work History] + [Education]
- [ ] Par employeur : nom, intitulé du poste, dates (début/fin ou « actuel »),
      missions, ville/état/pays, motif de départ
- [ ] Entrée UPS pré-existante : confirmer / corriger / compléter
- [ ] Éducation : « aucune » (laisser la case cochée) OU par diplôme :
      école, diplôme, domaine, année d'obtention

## C. Banque → [Direct Deposit]
- [ ] Nom de la banque, pays (USA/Canada)
- [ ] Type de compte (Checking/Savings), Routing Number (9 chiffres), Account Number
- [ ] Jusqu'à 10 comptes possibles — préciser l'ordre (compte de solde en dernier)

## D. Fiscal → [W-2 Consent] + [Federal W-4]
- [ ] Consentement W-2 électronique : oui / non
- [ ] Statut marital fiscal W-4 (Single / Married filing jointly / Head of household…)
- [ ] Étape 2 : plusieurs emplois ou conjoint salarié ? (oui/non + montants)
- [ ] Enfants / personnes à charge : montants ; autres revenus ; déductions ;
      retenue supplémentaire ; statut « Exempt » (oui/non)
- [ ] **État fiscal réel** (le formulaire pré-sélectionne « AK » — à corriger)
- [ ] Date de premier jour de travail

## E. Statut légal → Pôle 1 du Master Profile
- [ ] Statut d'autorisation de travail : EAD (C08/C09/TPS), Green Card, ou citoyen US
- [ ] Numéro d'autorisation + date d'expiration (+ n° de récépissé I-797C si renouvellement en cours)
- [ ] Traductions assermentées ATA / affidavits notariés : existent ? (oui/non + refs)

## F. Carrière → Pôle 3 du Master Profile
- [ ] Certifications : Forklift OSHA, OSHA 10, bilingue, WMS/RF Scanner, permis de conduire (+ refs)
- [ ] Corridor géographique cible (CVG Hebron / Erlanger-Florence / Cincinnati Nord)
- [ ] Files de dispatch souhaitées (Amazon Air CVG / DHL / Kroger / Wayfair)

## G. Consentements Adobe Sign → revue + décision du client
- [ ] Screening Deduction Auth : accepte la déduction $40 (casier) + $20 (dépistage) ?
- [ ] Employee Safety Guide 2026 : lu (9 pages)
- [ ] Policy and Procedures 2026 : lu — **13 items à parapher un par un**
- [ ] Terms of Employment 2026 : lu (at-will + background check)
- [ ] Drug Screen Authorization : consent
- [ ] Release Form 2026 : consent (casier + références)
- [ ] **Essential Job Functions 2026 : 48 réponses Yes/No** — seul le client peut répondre
      (la liste exacte des 48 questions sera extraite du document pour réponse écrite)
- [ ] **Employee Agreement 2026 : non-concurrence 12 mois, pénalités jusqu'à $10 000**
      → revue juridique avant signature (oui/non + décision)
- [ ] LLH Healthcare : s'enrôler ou opt-out (opt-out = appeler le (800) 280-8034)
- [ ] LLH Flyer : lu
- [ ] Child Labor & Human Rights : lu
- [ ] Insurance Election : décision — s'enrôler via ebaenrollment.com/644219 ou accuser réception
- [ ] Biometric Consent (Labor Source) : consent (données détruites en fin d'emploi, révocable par écrit)

## H. Porte de signature — autorisation explicite
- [ ] Le client a relu les textes juridiques (surtout G : non-concurrence, W-4, dépistage, biométrie)
- [ ] Autorisation de signature : liste exacte des documents couverts + date/heure
- [ ] Mode de signature : **Type** (nom tapé) — confirmé sur les 15 documents

---
*Une fois cette fiche complète → compilation du Master Profile JSON → exécution :
4 formulaires in-portal remplis + 15 documents Adobe Sign préparés jusqu'à la porte,
signature selon le mode choisi par le client.*
